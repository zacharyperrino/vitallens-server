# Migrations

Exported from the live project's `supabase_migrations.schema_migrations`
(applied via the Supabase MCP). These capture all schema changes made since
2026-07-04. The BASE schema (tables created before then, via dashboard/scripts)
is not represented here — run `supabase db pull` once with the Supabase CLI to
capture a full baseline, then apply new changes as migration files.
